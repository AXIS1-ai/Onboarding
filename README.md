# AXIS 1 — Onboarding de Cliente

Sistema simples em HTML, CSS e JavaScript para rodar no GitHub Pages.

## Arquivos

- index.html
- style.css
- script.js

## Como subir no GitHub

1. Crie um repositório novo, por exemplo: axis1-onboarding
2. Faça upload dos 3 arquivos.
3. Vá em Settings > Pages.
4. Em Branch, selecione main e /root.
5. Aguarde o link do GitHub Pages ficar ativo.

## Funções

- Formulário em etapas.
- Salva rascunho no navegador.
- Gera resumo final.
- Copia resumo.
- Baixa TXT.
- Exporta JSON.
- Envia resumo para o WhatsApp da AXIS 1.
